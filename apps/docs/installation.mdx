## One package

```bash
npm install -g @blueagent/cli
```

Gives you two commands:

| Command | Description |
|---------|-------------|
| `blue` | Direct CLI — `blue idea "..."`, `blue audit "..."`, etc. |
| `blueagent` | Interactive TUI — arrow keys to navigate |

## Requirements

- Node.js 18+
- `VIRTUALS_API_KEY` — set in `~/.blue-agent/config.toml` or as env var

## Set your API key

```toml
# ~/.blue-agent/config.toml
virtuals_api_key = "your_key_here"
```

Or via environment:

```bash
export VIRTUALS_API_KEY=your_key_here
```

Inference runs through Virtuals (`https://compute.virtuals.io/v1`). Leave the model
unset and the CLI uses the `@blueagent/core` default; pin one with `VIRTUALS_MODEL`
only if you know it is in the live Virtuals catalog.

## Verify install

```bash
blue doctor
```

## Update

```bash
npm update -g @blueagent/cli
```
